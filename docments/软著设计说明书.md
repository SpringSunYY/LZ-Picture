## 第 1 章 引言

### 1.1 编写目的

本说明书面向《计算机软件著作权登记》需要，对"荔枝云图库（LZ-Picture）"软件系统进行完整、规范化描述。本说明书详细阐述了系统的设计目标、整体架构、功能模块、关键算法、数据库结构、对外接口以及运行部署方案，作为软件产品登记的支撑材料，同时也为后续的开发、测试、运维以及二次扩展提供统一规范。

### 1.2 项目背景

随着短视频、自媒体和 AIGC 内容创作的爆发式增长，图像内容的生产、存储、整理、分享、协作、二次创作已经形成庞大的产业需求。个人创作者普遍使用"图床 + 网盘 + 即时通讯"组合管理图像，团队又需要"项目素材库 + 版本管理 + 权限协作"的能力。传统的图床工具仅解决"上传与访问"单一环节，无法满足团队协作、积分激励、AI 生图、统计运营等复合场景。

**荔枝云图库（LZ-Picture）** 正是为解决上述痛点而设计的"一站式"图像内容平台。系统以 Spring Boot 3 + Vue 3 全栈技术为基础，向下对接阿里云 OSS（对象存储）、阿里云短信、支付宝、即梦 AI 等成熟云服务，向上提供面向 C 端用户、B 端运营团队以及后台管理员的三类使用角色，覆盖图像上传管理、团队空间协作、积分体系运营、AI 生图、统计大屏等完整业务。

## 第 2 章 软件概述

### 2.1 软件简介

荔枝云图库（LZ-Picture）是一个面向图像内容创作与运营场景的**综合性云端图像管理平台**。系统同时提供用户端（C 端，B/S）、管理端（B 端，B/S）以及运营大屏三类入口，集成"图像上传、压缩、水印、分类、标签、推荐、评论、点赞、收藏、下载、分享"等基础图床能力，进一步融合"团队空间、积分充值、支付宝支付、AI 文生图/图生图"等业务能力，并以"统计大屏"为运营管理提供数据支撑。

系统采用"前后端分离 + 单体多模块"架构：前端包含 Picture-ui（用户端，Vue 3 + Tailwind）、Picture-back-ui（管理端，Vue 3 + Element Plus）两个 Web SPA；后端基于 Spring Boot 3，将功能拆分为 12 个 Maven 子模块聚合部署，分别承担认证、用户、图片、空间、积分、AI、定时任务、系统管理、代码生成器等职责。

## 第 3 章 总体设计

### 3.1 设计思想与原则

荔枝云图库在设计阶段遵循以下原则：

1. **前后端分离**：后端只输出 RESTful JSON，前端负责渲染与交互；
2. **单体多模块**：使用 Spring Boot + Maven Module 拆分业务，便于协作与编译加速；
3. **配置与代码分离**：所有可变配置（AI 模型参数、积分套餐、业务字典）入表，运行时通过 Redis 缓存读取；
4. **约定优于配置**：基于 RuoYi-Vue 增强版，统一 Controller/Service/Mapper/VO/DTO 分层；
5. **AOP 统一非业务**：通过自定义注解 + AOP 实现缓存、排序、日志、限流；
6. **策略模式 + 配置化**：AI 多模型以"接口 + JSON 配置"接入，新增模型无需改代码；
7. **安全优先**：JWT + Redis 黑名单、XSS 过滤、SQL 注入防护（MyBatis Plus 参数化）；
8. **可观测性**：登录/操作日志、登录失败锁定、慢 SQL 监控、服务监控大屏。

### 3.2 系统总体架构

本系统采用经典 B/S 三层架构，整体分为：**前端表示层**、**后端服务层**、**存储与中间件层**、**外部服务层**。

### 4.1 模块一：基于注解的自定义缓存（@CustomCacheable / @CustomCacheEvict）

#### 4.1.1 模块定位

针对系统中"分类/标签/字典/配置"等读多写少的查询接口，传统做法是每个方法手动调用 RedisCache.set/get，容易出现"忘记清缓存"、"key 拼错"、"过期时间不一致"等问题。**本模块通过自定义注解 + AOP + SpEL 表达式**实现"零侵入式"缓存，并支持嵌套字段、整体参数作为 key、批量清除模糊匹配 key。

#### 4.1.2 注解定义

```java
/**
 * 自定义缓存注解，方法返回值会被自动缓存到 Redis
 * 支持嵌套字段（如 "request.userId"）和分页缓存
 */
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface CustomCacheable {
    String keyPrefix();                              // 业务前缀，必填
    String keyField() default "";                    // 嵌套 key 字段，支持 SpEL
    long expireTime() default 3600L;                 // 过期时间（秒）
    boolean paginate() default false;                // 是否启用分页缓存
    String pageNumberField() default "";             // 页码字段
    String pageSizeField() default "";               // 每页大小字段
    boolean useQueryParamsAsKey() default false;     // 是否将整个查询对象序列化进 key
}
```

```java
/**
 * 自定义缓存删除注解，支持单 key、批量 key、模糊 key
 */
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface CustomCacheEvict {
    String[] keyPrefixes();                          // 要删除的 key 前缀集合
    String[] keyFields() default {};                 // 嵌套字段
    boolean useQueryParamsAsKey() default false;     // 拼接参数 JSON 模糊删除
}
```

#### 4.1.3 流程图

```
                       ┌──────────────────────┐
                       │  客户端发起查询请求   │
                       └──────────┬───────────┘
                                  ▼
                       ┌──────────────────────┐
                       │ 进入被 @CustomCache- │
                       │   able 标注的方法     │
                       └──────────┬───────────┘

                  └────────────┬──────────────┘
                               ▼
                  ┌────────── 命中？ ───────────┐
                  │ 是                        │ 否
                  ▼                          ▼
        ┌─────────────────┐        ┌──────────────────────┐

  3. useQueryParamsAsKey=true：用 SCAN + MATCH prefix* 模糊删除
```

#### 4.1.4 关键算法：SpEL 解析

```java
public class SpelKeyParser {

    private static final SpelExpressionParser PARSER = new SpelExpressionParser();

    /**
     * 把形如 "request.userId" 的字段路径从入参中解析出来，作为缓存 key 的一部分
     */
    public static String parse(String spel, Object root) {
        if (StringUtils.isEmpty(spel)) return "";
        Expression expression = PARSER.parseExpression(spel);
        Object value = expression.getValue(root);
        return value == null ? "" : value.toString();
    }

    /**
     * 拼装完整缓存 key：模块名:keyPrefix:keyField[:pageNum-pageSize]
     */
    public static String buildKey(String module, String keyPrefix, String keyField,
                                  Object root, boolean paginate,
                                  String pageNumberField, String pageSizeField,
                                  boolean useQueryParams, long expire) {
        StringBuilder sb = new StringBuilder();
        sb.append(module).append(COMMON_SEPARATOR_CACHE)
          .append(keyPrefix);
        if (StringUtils.isNotEmpty(keyField)) {
            sb.append(COMMON_SEPARATOR_CACHE).append(parse(keyField, root));
        }
        if (paginate) {
            String pn = parse(pageNumberField, root);
            String ps = parse(pageSizeField, root);
            sb.append(COMMON_SEPARATOR_CACHE).append(pn).append("-").append(ps);
        }
        if (useQueryParams) {
            String json = JSONObject.toJSONString(root);
            sb.append(COMMON_SEPARATOR_CACHE).append(DigestUtils.md5Hex(json));
        }
        return sb.toString();
    }
}
```

### 4.2 模块二：基于注解的安全排序（@CustomSort）

#### 4.2.1 模块定位

管理端表格常需要"点击列头排序"。若直接把前端传入的字段名拼到 SQL `ORDER BY` 后，存在 SQL 注入风险；若每个 Service 写死排序，又难以满足多列组合排序。**本模块通过自定义注解 + AOP 自动把"前端字段名"映射到"数据库字段名"，并校验合法性，规避注入。**

#### 4.2.2 注解定义

```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface CustomSort {
    String[] sortFields() default {};            // 前端允许的字段名
    String[] sortMappingFields() default {};     // 映射到数据库的字段名
}
```

#### 4.2.3 流程图

```
前端 el-table 列头点击
        │
        ▼
携带 { orderByColumn, isAsc } 调用查询接口
        │
        ▼
@CustomSort 切面拦截
        │
        ├── 1. 校验 orderByColumn 是否在 sortFields 白名单中
        │      ├─ 不在：直接放行，使用默认排序
        │      └─ 在：继续
        │
        ├── 2. 根据下标取 sortMappingFields 中对应的真实列名
        │
        ├── 3. 拼出 "ORDER BY <realColumn> <ASC|DESC>"
        │
        ├── 4. 写入 BaseEntity.params.sortSql（ThreadLocal 传递）
        │
        ▼
MyBatis 在 mapper.xml 引用 ${params.sortSql} 完成排序
        │
        ▼
返回结果
```

#### 4.2.4 关键实现

```java
@Aspect
@Component
public class CustomSortAspect {

    @Around("@annotation(customSort)")
    public Object around(ProceedingJoinPoint pjp, CustomSort customSort) throws Throwable {
        Object[] args = pjp.getArgs();
        if (args == null || args.length == 0) return pjp.proceed();

        for (Object arg : args) {
            if (arg instanceof BaseQuery q) {
                String orderByColumn = q.getParams() == null ? null
                    : (String) q.getParams().get("orderByColumn");
                Object isAscObj = q.getParams() == null ? null
                    : q.getParams().get("isAsc");
                if (StringUtils.isEmpty(orderByColumn) || isAscObj == null) {
                    return pjp.proceed();
                }
                int idx = Arrays.asList(customSort.sortFields()).indexOf(orderByColumn);
                if (idx < 0) return pjp.proceed(); // 非法字段 → 默认排序
                String realColumn = customSort.sortMappingFields()[idx];
                String direction = Boolean.TRUE.equals(isAscObj) ? "ASC" : "DESC";
                q.getParams().put("sortSql", " ORDER BY " + realColumn + " " + direction);
                break;
            }
        }
        return pjp.proceed();
    }
}
```

mapper.xml 引用：

```xml
<choose>
    <when test="params.sortSql != null and params.sortSql != ''">
        ${params.sortSql}
    </when>
    <otherwise>
        ORDER BY create_time DESC
    </otherwise>
</choose>
```

```java
@PostMapping("/alipay/notify")
public String alipayNotify(HttpServletRequest request) {
    Map<String, String> params = convertRequestParamMap(request);
    boolean signVerified = AlipaySignature.rsaCheckV1(
        params, alipayPublicKey, "UTF-8", "RSA2");
    ThrowUtils.throwIf(!signVerified, "验签失败");

    String outTradeNo = params.get("out_trade_no");
    String tradeStatus = params.get("trade_status");

    if ("TRADE_SUCCESS".equals(tradeStatus) || "TRADE_FINISHED".equals(tradeStatus)) {
        // 幂等：以 outTradeNo + status=已支付 为唯一键
        boolean updated = rechargeInfoService.lambdaUpdate()
            .eq(RechargeInfo::getOrderNo, outTradeNo)
            .eq(RechargeInfo::getOrderStatus, RECHARGE_STATUS_0)
            .set(RechargeInfo::getOrderStatus, RECHARGE_STATUS_1)
            .set(RechargeInfo::getPayTime, LocalDateTime.now())
            .set(RechargeInfo::getTradeNo, params.get("trade_no"))
            .update();
        if (updated) {
            accountInfoService.rechargeSuccess(outTradeNo);
        }
    }
    return "success"; // 必须返回 success，支付宝才会停止重试
}
```

```java
@Aspect
@Component
public class SearchLogAspect {

    @Around("@annotation(searchLog)")
    public Object around(ProceedingJoinPoint pjp, SearchLog searchLog) throws Throwable {
        long start = System.currentTimeMillis();
        Object result = pjp.proceed();
        long cost = System.currentTimeMillis() - start;

        // 异步落库，避免影响主链路
        executor.submit(() -> {
            try {
                SearchLogInfo log = new SearchLogInfo();
                log.setUserId(SecurityUtils.getUserId());
                log.setIp(ServletUtils.getClientIP());
                log.setUa(ServletUtils.getUserAgent());
                log.setKeyword(extractKeyword(pjp));
                log.setHitCount(extractHitCount(result));
                log.setCostMs(cost);
                log.setScene(searchLog.value());
                searchLogInfoService.save(log);
            } catch (Exception e) {
                log.error("search log write failed", e);
            }
        });
        return result;
    }
}
```

## 第 6 章 接口设计

### 6.1 接口设计原则

1. URL 命名采用**业务名 + 子资源**的 RESTful 风格，避免暴露数据库表名（但不强制全 RESTful，CRUD 兼容 /list /export）；
2. 用户端 `/user/**`、管理端 `/admin/**`，路径前缀与代码模块一一对应；
3. 所有写接口要求 `POST/PUT/DELETE`，所有列表统一 `POST /list` 接收 `TableSupport` 封装的 query；
4. 所有需要鉴权的接口必须携带 `Authorization: Bearer <jwt>`（过滤器全局解析）；
5. 列表接口统一返回 `TableDataInfo { total, rows, code, msg }`；
6. 所有写接口幂等保护（基于业务主键 + 状态机）；
7. 关键写接口标注 `@Log` 注解，自动记录操作日志；
8. 导出接口统一 `POST /export`，底层走异步线程池生成 Excel；
9. 异常统一由 `GlobalExceptionHandler` 拦截并返回 `AjaxResult`。

### 6.2 统一响应结构

#### 6.2.1 AjaxResult（增删改、详情）

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": { ... }
}
```

#### 6.2.2 TableDataInfo（分页查询）

```json
{
  "code": 200,
  "msg": "查询成功",
  "total": 1234,
  "rows": [ ... ]
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | int | 业务码（200 成功，500 失败，401 未登录，403 无权限，4001~4xxx 业务异常） |
| msg | String | 提示信息 |
| data / total / rows | Object | 业务数据 |

#### 6.2.3 请求规范

**（1）请求头（必填）**

| Header | 必填 | 说明 |
| --- | --- | --- |
| `Content-Type` | 是 | 固定 `application/json;charset=UTF-8` |
| `Authorization` | 是（除登录/注册/公开接口） | `Bearer <jwt>`，由 `JwtAuthenticationFilter` 统一解析 |
| `Accept-Language` | 否 | `zh-CN` / `en-US`，用于国际化文案返回 |
| `X-Request-Id` | 否 | 客户端 UUID，用于链路追踪；服务端会覆盖并写入 MDC |
| `User-Agent` | 否 | 客户端标识，敏感接口风控辅助 |
| `X-Timestamp` | 是（写接口） | 客户端时间戳（毫秒），与当前时间偏差 >5min 拒绝，防重放 |
| `X-Sign` | 是（写接口） | 签名，`MD5(timestamp + secret + body)`，详见（4） |

**（2）请求方法与路径**

| 场景 | 方法 | 路径示例 | 说明 |
| --- | --- | --- | --- |
| 列表查询 | `POST` | `/user/picture/list` | 一律 POST，body 传 `query` |
| 详情 | `GET` | `/user/picture/{id}` | 路径参数 |
| 新增 | `POST` | `/admin/picture` |  |
| 修改 | `PUT` | `/admin/picture` | 全量修改 |
| 部分修改 | `POST` | `/admin/picture/edit` | 兼容 RuoYi 风格 |
| 删除 | `DELETE` | `/admin/picture/{ids}` | 支持批量 |
| 导出 | `POST` | `/admin/picture/export` | 异步生成 Excel |
| 文件上传 | `POST` | `/tool/upload` 或 OSS 直传 | `multipart/form-data` |
| 文件下载 | `GET` | `/tool/download?fileId=xxx` | 鉴权后 302 跳转 OSS 签名 URL |

**（3）请求参数规范**

- 列表查询统一包装：

  ```json
  {
    "query": {
      "pageNum": 1,
      "pageSize": 20,
      "orderByColumn": "createTime",
      "isAsc": "desc",
      "params": {
        "beginCreateTime": "2026-01-01",
        "endCreateTime": "2026-06-15",
        "categoryId": "10"
      }
    }
  }
  ```
- 排序字段必须落在 `@CustomSort` 白名单中，未声明字段一律忽略，防止 SQL 注入。
- 时间统一 ISO-8601（`yyyy-MM-dd HH:mm:ss`）或毫秒时间戳，由 `JacksonConfig` 统一解析。
- 分页默认 `pageSize=10, max=200`；超过 200 自动截断，防止慢 SQL。
- 文件上传大小限制：图片 ≤ 10MB，压缩包/Excel ≤ 50MB（在 Nginx 与 Spring Boot 双端限制）。

**（4）签名规则（写接口必填）**

```
sign = MD5( X-Timestamp + "&" + secret + "&" + body )
```

| 步骤 | 说明 |
| --- | --- |
| 1 | 客户端从 `Redis` / `localStorage` 读取 `secret`（由登录接口下发，过期时间 = Token 过期时间） |
| 2 | 拼接 `timestamp & secret & body`（body 为原始 JSON 字符串，不做字段重排） |
| 3 | `MD5` 后转 32 位小写，填入 `X-Sign` |
| 4 | 服务端 `SignAspect` 切面拦截 `@RequireSign` 注解方法，校验通过放行，失败抛 `403 SIGN_INVALID` |

**（5）幂等性**

- 创建类接口支持客户端传 `Idempotency-Key`（UUID），服务端以 `(userId, idempotencyKey)` 在 Redis 缓存 24h；重复请求直接返回首次结果。
- 状态机接口（订单/支付/审核）按业务主键 + 当前状态判断，已完成状态拒绝重复操作。

**（6）限流策略**

- 登录、注册、短信下发：单 IP 1 分钟 5 次（Redis 滑动窗口）。
- 文件上传：单用户 1 分钟 20 次、单 IP 1 分钟 60 次。
- AI 生图：单用户 1 分钟 3 次、单用户 1 天 100 次。
- 写接口全局：单用户 1 秒 10 次，超出返回 `429 RATE_LIMIT`。

### 6.14 接口安全

1. **JWT 鉴权**：HS256，载荷包含 userId、username、roles、spacePerms、exp；
2. **黑名单**：注销后将 token 加入 Redis 黑名单（key=`auth:blacklist:{jti}`，TTL=剩余过期时间）；
3. **数据权限**：基于 `@DataScope` 注解 + ThreadLocal 拼接 SQL；
4. **限流**：`@RateLimiter` 注解，关键接口 60s 内不超过 30 次；
5. **XSS 过滤**：基于 Jsoup 框架级过滤；
6. **CSRF**：前后端分离 + 携带 Token，无需 CSRF token。

### B.2 全局异常处理

文件：`Picture/picture-framework/src/main/java/com/lz/framework/web/exception/GlobalExceptionHandler.java`

```java
package com.lz.framework.web.exception;

@RestControllerAdvice
public class GlobalExceptionHandler {
    private static final Logger log = LoggerFactory.getLogger(GlobalExceptionHandler.class);

    /** 权限校验异常 */
    @ExceptionHandler(AccessDeniedException.class)
    public AjaxResult handleAccessDeniedException(AccessDeniedException e, HttpServletRequest request) {
        String requestURI = request.getRequestURI();
        log.error("请求地址'{}',权限校验失败'{}'", requestURI, e.getMessage());
        return AjaxResult.error(HttpStatus.FORBIDDEN, "没有权限，请联系管理员授权");
    }

    /** 请求方式不支持 */
    @ExceptionHandler(HttpRequestMethodNotSupportedException.class)
    public AjaxResult handleHttpRequestMethodNotSupported(HttpRequestMethodNotSupportedException e, HttpServletRequest request) {
        String requestURI = request.getRequestURI();
        log.error("请求地址'{}',不支持'{}'请求", requestURI, e.getMethod());
        return AjaxResult.error(e.getMessage());
    }

    /** 业务异常 */
    @ExceptionHandler(ServiceException.class)
    public AjaxResult handleServiceException(ServiceException e, HttpServletRequest request) {
        log.error(e.getMessage(), e);
        Integer code = e.getCode();
        return StringUtils.isNotNull(code) ? AjaxResult.error(code, e.getMessage()) : AjaxResult.error(e.getMessage());
    }

    /** 请求路径中缺少必需的路径变量 */
    @ExceptionHandler(MissingPathVariableException.class)
    public AjaxResult handleMissingPathVariableException(MissingPathVariableException e, HttpServletRequest request) {
        String requestURI = request.getRequestURI();
        log.error("请求路径中缺少必需的路径变量'{}',发生系统异常.", requestURI, e);
        return AjaxResult.error(String.format("请求路径中缺少必需的路径变量[%s]", e.getVariableName()));
    }

    /** 请求参数类型不匹配 */
    @ExceptionHandler(MethodArgumentTypeMismatchException.class)
    public AjaxResult handleMethodArgumentTypeMismatchException(MethodArgumentTypeMismatchException e, HttpServletRequest request) {
        String requestURI = request.getRequestURI();
        String value = Convert.toStr(e.getValue());
        if (StringUtils.isNotEmpty(value)) { value = EscapeUtil.clean(value); }
        log.error("请求参数类型不匹配'{}',发生系统异常.", requestURI, e);
        return AjaxResult.error(String.format("请求参数类型不匹配，参数[%s]要求类型为：'%s'，但输入值为：'%s'", e.getName(), e.getRequiredType().getName(), value));
    }

    /** 拦截未知的运行时异常 */
    @ExceptionHandler(RuntimeException.class)
    public AjaxResult handleRuntimeException(RuntimeException e, HttpServletRequest request) {
        String requestURI = request.getRequestURI();
        log.error("请求地址'{}',发生未知异常.", requestURI, e);
        return AjaxResult.error(e.getMessage());
    }

    /** 系统异常 */
    @ExceptionHandler(Exception.class)
    public AjaxResult handleException(Exception e, HttpServletRequest request) {
        String requestURI = request.getRequestURI();
        log.error("请求地址'{}',发生系统异常.", requestURI, e);
        return AjaxResult.error(e.getMessage());
    }

    /** 自定义验证异常（表单） */
    @ExceptionHandler(BindException.class)
    public AjaxResult handleBindException(BindException e) {
        log.error(e.getMessage(), e);
        String message = e.getAllErrors().get(0).getDefaultMessage();
        return AjaxResult.error(message);
    }

    /** 自定义验证异常（@RequestBody） */
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public Object handleMethodArgumentNotValidException(MethodArgumentNotValidException e) {
        log.error(e.getMessage(), e);
        String message = e.getBindingResult().getFieldError().getDefaultMessage();
        return AjaxResult.error(message);
    }

    /** 演示模式异常 */
    @ExceptionHandler(DemoModeException.class)
    public AjaxResult handleDemoModeException(DemoModeException e) {
        return AjaxResult.error("演示模式，不允许操作");
    }

    /** sql 唯一键异常（友好提示） */
    @ExceptionHandler(SQLDuplicateKeyException.class)
    public AjaxResult handleSQLDuplicateKeyException(SQLDuplicateKeyException e) {
        String message = e.getCause().toString();
        if (StringUtils.containsIgnoreCase(message, "Duplicate entry")) {
            String[] msgs = message.split(" ");
            String msg = msgs[3] + "已存在";
            return AjaxResult.error(msg);
        }
        return AjaxResult.error(e.getMessage());
    }
}
```

> 设计要点：所有 Controller 抛出的异常（包括 Spring 框架异常、业务自定义 `ServiceException`、SQL 唯一键冲突、参数校验失败、请求方法不匹配）均由 `GlobalExceptionHandler` 统一拦截，最终以 `AjaxResult` 返回前端。返回值是 `AjaxResult`（B 端）或 `R`（C 端，单独的 `R<T>` 包装）二选一，具体由各 Controller 的 `RestControllerAdvice` 子切面决定。

### B.3 Token 服务

```java
package com.lz.framework.web.service;

@Component
public class TokenService {
    @Value("${token.header}")
    private String header;
    @Value("${token.secret}")
    private String secret;
    @Value("${token.expireTime}")
    private int expireTime;

    protected static final long MILLIS_SECOND = 1000;
    protected static final long MILLIS_MINUTE = 60 * MILLIS_SECOND;
    private static final Long MILLIS_MINUTE_TEN = 20 * 60 * 1000L;

    @Autowired
    private RedisCache redisCache;

    /** 创建令牌 */
    public String createToken(LoginUser loginUser) {
        String token = IdUtils.fastUUID();
        loginUser.setToken(token);
        setUserAgent(loginUser);
        refreshToken(loginUser);
        Map<String, Object> claims = new HashMap<>();
        claims.put(Constants.LOGIN_USER_KEY, token);
        return createToken(claims);
    }

    /** 从数据声明生成令牌（HS512 签名） */
    private String createToken(Map<String, Object> claims) {
        return Jwts.builder()
                .setClaims(claims)
                .signWith(SignatureAlgorithm.HS512, secret)
                .compact();
    }

    /** 解析令牌 */
    private Claims parseToken(String token) {
        return Jwts.parser()
                .setSigningKey(secret)
                .parseClaimsJws(token)
                .getBody();
    }

    /** 验证令牌有效期，相差不足 20 分钟自动刷新缓存 */
    public void verifyToken(LoginUser loginUser) {
        long expireTime = loginUser.getExpireTime();
        long currentTime = System.currentTimeMillis();
        if (expireTime - currentTime <= MILLIS_MINUTE_TEN) {
            refreshToken(loginUser);
        }
    }

    /** 刷新令牌有效期（写 Redis） */
    public void refreshToken(LoginUser loginUser) {
        loginUser.setLoginTime(System.currentTimeMillis());
        loginUser.setExpireTime(loginUser.getLoginTime() + expireTime * MILLIS_MINUTE);
        String userKey = getTokenKey(loginUser.getToken());
        redisCache.setCacheObject(userKey, loginUser, expireTime, TimeUnit.MINUTES);
    }

    /** 删除用户身份信息（注销） */
    public void delLoginUser(String token) {
        if (StringUtils.isNotEmpty(token)) {
            String userKey = getTokenKey(token);
            redisCache.deleteObject(userKey);
        }
    }

    private String getTokenKey(String uuid) {
        return CacheConstants.LOGIN_TOKEN_KEY + uuid;
    }
}
```

> 设计要点：JWT 仅保存 `LoginUser` 在 Redis 中的 uuid，完整的登录态（用户、角色、权限、IP、设备）落在 Redis，key=`login_tokens:<uuid>`，有效期与 token 一致（默认 30 分钟）；每次请求由 `JwtAuthenticationTokenFilter` 自动解析 + 距离过期 < 20min 时刷新，实现"无感续签"。

```java
package com.lz.picture.utils;

@Component
public class SpaceAuthUtils {
    public static final String SPACE_MEMBER_INFO_KEY       = "picture:space:user:member:";
    public static final String SPACE_MEMBER_INFO_KEY_USER  = "picture:space:user:space:";

    private static final int expireTime = 60 * 30;   // 30 分钟

    @Resource private ISpaceMemberInfoService spaceMemberInfoService;
    @Resource private ISpaceInfoService       spaceInfoService;
    @Resource private RedisCache              redisCache;

    /** 获取某用户的所有空间成员权限（userId:spaceId:roleType），先读 Redis */
    public Set<String> getSpaceMemberPerm(String userId) {
        String key = SPACE_MEMBER_INFO_KEY + userId;
        if (redisCache.hasKey(key)) {
            return redisCache.getCacheObject(key);
        }
        List<SpaceMemberInfo> list = spaceMemberInfoService.selectSpaceMemberInfoByUserId(userId);
        Set<String> hashSet = new HashSet<>();
        for (SpaceMemberInfo m : list) {
            hashSet.add(m.getUserId() + ":" + m.getSpaceId() + ":" + m.getRoleType());
        }
        redisCache.setCacheObject(key, hashSet, expireTime, TimeUnit.SECONDS);
        return hashSet;
    }

    /** 构建空间成员权限（userId:spaceId:roleType） */
    public String buildSpaceMemberPerm(String userId, String spaceId, String roleType) {
        return userId + ":" + spaceId + ":" + roleType;
    }

    /** 当前用户：是否是创建者 */
    public boolean checkSpaceCreatorPerm(String spaceId) {
        return checkSpaceMemberAnyPerm(buildSpaceMemberPerm(spaceId, PSpaceRoleEnum.SPACE_ROLE_0.getValue()));
    }

    /** 当前用户：是否有编辑权限（创建者/编辑者） */
    public boolean checkSpaceEditPerm(String spaceId) {
        return checkSpaceMemberAnyPerm(
                buildSpaceMemberPerm(spaceId, PSpaceRoleEnum.SPACE_ROLE_1.getValue()) + ","
                        + buildSpaceMemberPerm(spaceId, PSpaceRoleEnum.SPACE_ROLE_0.getValue()));
    }

    /** 删除该用户全部空间权限缓存（成员变更时调用） */
    public void deleteSpacePerm(String userId) {
        spaceInfoService.deleteSpaceTeamTableCacheByUserId(userId);
        deleteUserJoinSpace(userId);
        deleteSpaceMemberPerm(userId);
    }
}
```

> 设计要点：空间权限串 `userId:spaceId:roleType`（如 `u1:s10:SPACE_ROLE_0`），整个集合一次性缓存到 Redis，30 分钟过期。校验时仅 `Set.contains()`，O(1) 时间复杂度；成员/角色变更时通过 `deleteSpacePerm(userId)` 主动清缓存。

```java
@Service
public class AiGenerateStrategyExecutor {
    @Resource private IModelParamsInfoService modelParamsInfoService;
    @Resource private List<AiGenerateStrategyService> aiGenerateStrategyServiceList;  // Spring 自动注入所有实现
    @Resource private IAccountInfoService accountInfoService;

    /** 用户生成：循环 modelKey 列表 → 积分预扣 → 反射拿到 @AiGenerateStrategyConfig 匹配的执行器 */
    public List<GenerateLogInfo> executeUserGenerate(AiGenerateRequest request) {
        List<String> modelKeys = request.getModelKeys();
        List<GenerateLogInfoDto> generateLogInfoDtos = new ArrayList<>();
        ArrayList<GenerateLogInfo> logInfos = new ArrayList<>();
        Long totalPoints = 0L;
        for (String modelKey : modelKeys) {
            ModelParamsInfo modelParamsInfo = modelParamsInfoService.selectModelParamsInfoByModelKey(modelKey);
            ThrowUtils.throwIf(StringUtils.isNull(modelParamsInfo)
                    || !modelParamsInfo.getParamsStatus().equals(AiModelParamsStatusEnum.MODEL_PARAMS_STATUS_0.getValue()),
                    HttpStatus.NO_CONTENT, "模型参数不存在或者未启用");
            generateLogInfoDtos.add(new GenerateLogInfoDto(request, modelParamsInfo));
            totalPoints += modelParamsInfo.getPointsNeed() * request.getNumbers();
        }
        AccountInfo accountInfo = accountInfoService.selectAccountInfoByUserId(request.getUserId());
        ThrowUtils.throwIf(StringUtils.isNull(accountInfo) || accountInfo.getPointsBalance() < totalPoints, "积分不足");

        for (GenerateLogInfoDto info : generateLogInfoDtos) {
            for (AiGenerateStrategyService strategyService : aiGenerateStrategyServiceList) {
                AiGenerateStrategyConfig annotation = strategyService.getClass().getAnnotation(AiGenerateStrategyConfig.class);
                if (annotation.model().equals(info.getModel())) {
                    logInfos.addAll(strategyService.userGenerate(info));
                }
            }
        }
        return logInfos;
    }

    /** 任务查询：反射匹配 → 调用对应执行器 */
    public GenerateLogInfo executeQuery(GenerateLogInfo generateLogInfo, String username) {
        ModelParamsInfo modelParamsInfo = modelParamsInfoService.selectModelParamsInfoByModelKey(generateLogInfo.getModelKey());
        ThrowUtils.throwIf(StringUtils.isNull(modelParamsInfo), HttpStatus.NO_CONTENT, "模型参数不存在或者未启用");
        for (AiGenerateStrategyService aiGenerateStrategyService : aiGenerateStrategyServiceList) {
            AiGenerateStrategyConfig annotation = aiGenerateStrategyService.getClass().getAnnotation(AiGenerateStrategyConfig.class);
            if (annotation.model().equals(modelParamsInfo.getModel())) {
                return aiGenerateStrategyService.query(generateLogInfo, modelParamsInfo, username);
            }
        }
        return null;
    }
}
```

```java
package com.lz.common.annotation;

@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface CustomCacheable {
    String keyPrefix();                                  // 缓存 key 的前缀
    String keyField()      default "";                   // 从入参中提取 key 的字段路径（支持嵌套）
    long   expireTime()    default 10800L;               // 缓存时间（秒）
    boolean paginate()     default false;                // 是否启用分页缓存
    String pageNumberField() default "";                 // 页码字段
    String pageSizeField()   default "";                 // 每页大小字段
    boolean useQueryParamsAsKey() default false;         // 是否将整个查询对象转 JSON 作为 key
}
```

文件 2：`Picture/picture-framework/src/main/java/com/lz/framework/aspectj/CustomCacheAspect.java`

```java
@Aspect
@Component
public class CustomCacheAspect {
    @Resource private RedisCache redisCache;
    private static final String COMMON_SEPARATOR_CACHE = ":";
    private static final int    DEFAULT_PAGE_SIZE     = 30;
    private static final int    DEFAULT_PAGE_NUM      = 1;

    @Around("@annotation(customCacheable)")
    public Object around(ProceedingJoinPoint joinPoint, CustomCacheable customCacheable) throws Throwable {
        // 1. 取出注解参数
        String  keyPrefix           = customCacheable.keyPrefix();
        String  keyFieldPath        = customCacheable.keyField();
        boolean useQueryParamsAsKey = customCacheable.useQueryParamsAsKey();
        long    expireTime          = customCacheable.expireTime();
        boolean paginate            = customCacheable.paginate();

        // 2. 取出方法参数与参数名
        Object[] args = joinPoint.getArgs();
        MethodSignature signature = (MethodSignature) joinPoint.getSignature();
        String[] paramNames = signature.getParameterNames();

        // 3. 从入参中按字段路径取 key
        Object keyFieldValue = null;
        if (keyFieldPath != null && !keyFieldPath.isEmpty()) {
            keyFieldValue = getValueByParamNameAndFieldPath(paramNames, args, keyFieldPath);
        }
        String baseCacheKey = keyPrefix;
        if (keyFieldValue != null && !keyFieldValue.toString().isEmpty()) {
            baseCacheKey += COMMON_SEPARATOR_CACHE + keyFieldValue.toString();
        }
        if (useQueryParamsAsKey) {
            baseCacheKey = baseCacheKey + COMMON_SEPARATOR_CACHE + JSON.toJSONString(args);
        }

        // 4. 分页缓存 vs 详情缓存 分支
        if (paginate) {
            int pageNumber = extractIntValue(paramNames, args, customCacheable.pageNumberField(), DEFAULT_PAGE_NUM);
            int pageSize   = extractIntValue(paramNames, args, customCacheable.pageSizeField(),  DEFAULT_PAGE_SIZE);
            String pageCacheKey = baseCacheKey + COMMON_SEPARATOR_CACHE + pageNumber + COMMON_SEPARATOR_CACHE + pageSize;
            List<Object> cachedPage = redisCache.getCacheList(pageCacheKey, 0, pageSize - 1);
            if (cachedPage != null && !cachedPage.isEmpty()) return cachedPage;
            Object result = joinPoint.proceed();
            if (result instanceof List) {
                List<Object> resultList = (List<Object>) result;
                if (!resultList.isEmpty()) {
                    redisCache.setCacheListRightPushAll(pageCacheKey, resultList, (int) expireTime, TimeUnit.SECONDS);
                }
            }
            return result;
        } else {
            String cachedJson = redisCache.getCacheObject(baseCacheKey);
            if (cachedJson != null && !cachedJson.isEmpty()) {
                Class<?> returnType = ((MethodSignature) joinPoint.getSignature()).getReturnType();
                return JSON.parseObject(cachedJson, returnType);
            }
            Object result = joinPoint.proceed();
            String resultJson = JSON.toJSONString(result);
            redisCache.setCacheObject(baseCacheKey, resultJson, (int) expireTime, TimeUnit.SECONDS);
            return result;
        }
    }

    /** 嵌套字段路径取值（支持 "request.type.id"） */
    private Object getValueByParamNameAndFieldPath(String[] paramNames, Object[] args, String keyFieldPath) { /* 反射递归 */ }
}
```

> 设计要点：Service 方法上添加 `@CustomCacheable(keyPrefix="picture:tag:list", keyField="request.userId", expireTime=3600)` 即可自动接入 Redis 缓存，支持**详情缓存**与**分页缓存**两种模式（`paginate=true` 时按 List 缓存），并支持把入参 `useQueryParamsAsKey=true` 序列化进 key 防止多条件查询串。
