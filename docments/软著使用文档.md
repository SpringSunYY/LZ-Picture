## 1. 软件概述

### 1.1 软件基本信息

| 项目 | 内容 |
|------|------|
| 软件名称 | LZ-Picture |
| 版本号 | V1.0 |
| 软件类型 | 图像管理与AI生成平台 |

### 1.2 软件简介

LZ-PIcture是一款面向图像内容创作与运营场景的云端图像管理平台，提供图片上传管理、团队协作、AI图像生成、积分运营等完整业务能力。

### 1.3 系统入口

| 系统 | 访问地址 | 说明 |
|------|----------|------|
| 用户端（C端） | `http://localhost:80` | 面向普通用户，提供图片上传、AI生图等功能 |
| 管理端（B端） | `http://localhost:1226` | 面向管理员，提供系统管理、数据统计等功能 |
| 后端API | `http://localhost:8080` | 提供数据接口 |

### 1.4 主要功能模块

| 模块 | 功能说明 |
|------|----------|
| 用户模块 | 注册、登录、个人资料、用户主页 |
| 图片模块 | 上传下载、分类标签、评论点赞、搜索推荐 |
| 空间模块 | 团队空间、成员管理、文件夹管理 |
| 积分模块 | 充值套餐、积分消费、邀请返利 |
| AI模块 | 文生图、图生图、多模型支持 |
| 管理模块 | 用户管理、内容审核、数据统计、系统监控 |
| 运营大屏 | 用户数据统计、图片数据统计、积分数据统计 |

## 3. 安装与启动

### 3.1 配置数据库

编辑文件 `Picture/picture-admin/src/main/resources/application-druid.yml`

修改以下配置：

```yaml
url: jdbc:mysql://数据库地址:3306/数据库名
username: 数据库用户名
password: 数据库密码
```

### 3.2 配置Redis

编辑文件 `Picture/picture-admin/src/main/resources/application.yml`

修改Redis配置：

```yaml
spring:
  data:
    redis:
      host: Redis服务器地址
      port: 6379
      database: 8
      password: Redis密码
```

### 3.3 启动后端服务

```bash
cd Picture
mvn clean install
mvn spring-boot:run
```

启动成功后显示：`Started PictureApplication in XXX seconds (process running for XXX)`

### 3.4 启动用户端

```bash
cd Picture-ui
npm install
npm run dev
```

访问：`http://localhost:80`

### 3.5 启动管理端

```bash
cd Picture-back-ui
npm install
npm run dev
```

访问：`http://localhost:1226`

## 4. 用户端功能使用

本节主要介绍用户在客户端使用平台的核心功能，包括登录注册、图片浏览与搜索、团队空间管理、积分系统、AI生图、用户中心等模块的使用方法。

### 4.1 登录与注册

登录注册模块用于用户的身份认证和账号管理，支持多种登录方式保障账号安全。

#### 4.1.1 登录

**入口：** 首页右上角「登录」按钮或未登录状态访问任意需认证页面

登录页面支持以下方式：

| 登录方式 | 操作步骤 |
|---------|---------|
| **手机号+密码登录** | 输入手机号（+86前缀）→ 输入用户名 → 输入密码 → 点击登录 |
| **记住我** | 勾选"记住我"后下次登录可快速登录 |
| **短信验证码登录** | 点击"更多"→ 选择"短信登录"→ 输入手机号→ 获取验证码→ 登录 |
| **忘记密码** | 点击"更多"→ 选择"忘记密码"→ 输入手机号→ 验证身份→ 重置密码 |

**登录说明：**

- 手机号登录：支持中国（+86）区号，手机号用于接收验证码和找回密码
- 用户名登录：独立于手机号，可使用字母、数字、下划线组合
- 登录成功后自动跳转首页，并显示用户头像

![使用文档-登录](assets/使用文档-登录.jpg)

#### 4.1.2 注册

**入口：** 登录页面点击"更多"→ "注册账号"

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 填写手机号 | 必填，用于接收验证码 |
| 2 | 获取短信验证码 | 点击"发送验证码"，收到短信后填写 |
| 3 | 设置用户名 | 必填，用于登录，唯一不可重复 |
| 4 | 设置登录密码 | 必填，8-20位，建议包含字母和数字 |
| 5 | 用户协议 | 登录即表示同意用户协议 |
| 6 | 点击注册 | 完成注册后自动登录并跳转首页 |

![使用文档-注册](assets/使用文档-注册.jpg)

#### 4.1.3 忘记密码

**入口：** 登录页面"更多"→ "忘记密码"

| 步骤 | 操作 |
|------|------|
| 1 | 输入注册手机号 |
| 2 | 获取并填写短信验证码 |
| 3 | 输入新密码（8-20位） |

### 4.4 图片上传

图片上传模块用于用户上传自己的图片作品到平台，审核通过后可在公共图库展示，也可设置积分供其他用户下载获取收益。

**入口：** 登录后导航栏「上传」按钮

#### 4.4.1 上传流程

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 选择图片 | 点击上传区域或拖拽图片到上传框，支持批量选择 |
| 2 | 图片名称 | 必填，2~32个字符 |
| 3 | 选择分类 | 必填，从分类列表中选择（一级分类+二级分类） |
| 4 | 添加标签 | 可选，最多添加5个标签，用于搜索匹配 |
| 5 | 设置积分 | 可选，图片申请公开时可以设置，0为免费 |
| 6 | 提交审核 | 点击提交，图片进入待审核状态 |
| 7 | 支持格式 | JPG、JPEG、PNG、GIF、WebP |
| 8 | 单张大小 | 最大50MB |
| 9 | 图片申请公开 | 上传后需申请未公开，且管理员审核通过才能公开显示，注：此页在右侧栏图片管理→ 我的图片 |

### 4.5 团队空间

### 4.7 AI生图

AI生图模块集成多种AI模型，用户可以通过文字描述生成图片（文生图）或基于参考图片生成新图片（图生图），支持即梦AI各种模型生图。

**入口：** 导航栏「荔枝AI」进入AI页面，点击「生成图片」生成图片

#### 4.7.1 文生图

**功能：** 通过文字描述生成图片

| 步骤 | 操作 |
|------|------|
| 1 | 选择「文生图」Tab |
| 2 | 在创意描述框输入图片描述（最多800字符） |
| 3 | 可点击"推荐"获取提示词推荐 |
| 4 | 选择AI模型（不同模型收费不同） |
| 5 | 点击"开始生成" |
| 6 | 查看生成结果，支持重新生成或保存 |

![使用文档-文生图](assets/使用文档-文生图.jpg)

#### 4.7.2 图生图

**功能：** 基于参考图片和文字描述生成新图片

| 步骤 | 操作 |
|------|------|
| 1 | 选择「图生图」Tab |
| 2 | 上传参考图片（JPG/PNG/JPEG等，最大5MB） |
| 3 | 在创意描述框输入修改要求 |
| 4 | 选择AI模型 |
| 5 | 点击"开始生成" |
| 6 | 查看生成结果 |

![使用文档-图生图](assets/使用文档-图生图.jpg)

#### 4.7.3 AI模型

| 模型 | 说明 |
|------|------|
| 即梦AI 文生图2.1 | 文字生成能力：支持生成准确的中文汉字和英文字母。构图、光影、色彩、质感全面提升，画面层次感增强。最高生成 768*768px 图片，默认超分 |
| 即梦AI 文生图3.0 | 在文字响应准确度、图文排版、层次美感和语义理解能力上显著提升，支持输出高清大图。最高生成 2048*2048px 图片，采用异步生成 |
| 即梦AI 文生图3.1 | 画面美感塑造、风格精准多样及画面细节丰富度提升显著，同时兼具文字响应效果。最高生成 2048*2048px 图片，采用异步生成 |
| 即梦AI 图生图3.0 | 支持基于文本指令进行图像编辑，精准执行编辑指令并保持图像内容完整性（如人物特征及精细细节），尤其在真实图像和海报图文设计场景表现卓越。最高生成 2016*2016px 图片，采用异步生成，图片最大 4.7M |

每个模型设置有对应的积分消耗设置。

#### 4.7.4 AI生成记录

**入口：** 荔枝AI「资产」Tab

| 功能 | 说明 |
|------|------|
| 查看记录 | 查看历史生成的图片 |

## 6. 常见问题

### 6.1 登录注册问题

**Q: 如何注册用户？**
- 您可以通过点击主页上的"注册"按钮，然后按照提示填写必要信息来注册用户
- 请确保提供准确的个人信息以便我们为您提供更好的服务

**Q: 如何重置密码？**
- 在登录页面，点击"忘记密码"链接
- 输入您的注册手机号，我们将向您发送重置密码的验证码
- 请检查您的垃圾短信文件夹，以防短信被误判

**Q: 如何创建账户？**
- 用户在充值积分后平台会自动为您创建账户，并自动充值积分

**Q: 收不到验证码？**
- 检查手机号是否正确
- 稍后重试
- 检查短信拦截/垃圾箱

### 6.2 图片问题

**Q: 上传失败？**
- 检查网络连接
- 确认图片格式（JPG、JPEG、PNG、GIF、WebP）和大小（最大50MB）
- 刷新页面重试

**Q: 图片审核需要多久？**
- 上传后需管理员审核才能公开显示
- 审核时间视当前审核队列而定

### 6.3 积分问题

**Q: 充值未到账？**
- 稍等3-5分钟
- 检查订单是否已支付
- 联系客服查询

**Q: 如何免费获取积分？**
- 图片被他人下载
